# Ajith Kanna — Portfolio

## Run locally (VS Code)

1. Install Node.js 20+ from https://nodejs.org
2. Open this folder in VS Code (File > Open Folder)
3. Open the terminal (Ctrl + `) and run:

```sh
npm install
npm run dev
```

4. Open http://localhost:8080

## Edit your content

All text, links, reels, photos and stats are in `src/data/portfolio.ts`.
Images are in `src/assets/`.

## Videos

Compressed reels live in `public/videos/` and their cover frames in `public/posters/`.
To add a missing video (for example `kara-movie.mp4`), save it in `public/videos/` with that exact name.
